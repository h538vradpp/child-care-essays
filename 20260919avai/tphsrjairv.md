# 北京协和医院生殖中心挂号攻略是怎样的?

北京协和辅助生殖中心挂号有六种方式分别是APP预约；电话预约：114电话或者114北京市预约挂号平台可以在放号瞬间抢号；国际医疗部门诊预约；网络预约挂号及取号流程；银医卡自助预约；自助机预约等方式。去协和看病，一定要提前做一些准备工作，查看好所看医生的出诊时间。大多数患者来京看病都要挂专家号，而专家并不是每天出诊，有的每周只出诊一次，有时还停诊。

在协和医院看病首先要在窗口办理就医卡，因为协和医院APP挂号首先要办卡建档。而且协和医院是无纸化办公，医生开出的检查单和药物全部存在就医卡中。所以就医卡至关重要。协和医院挂号的方式：

- 1. 预约挂号：可通过手机APP实现预约挂号，可自由选择科室、医生和就诊时间，确认预约信息后直接在APP上支付医事服务费；
- 2. 当日挂号：没有提前预约的情况下，如果当日需要就诊也可通过APP进行挂号；
- 3. 预约取号：在其他平台（例如诊间预约、诊间加号、114电话）预约的号，可通过APP预约取号功能支付医事服务费。（d）复诊预约：如果医生已开通复诊权限，在手机APP上通过复诊预约功能进行预约挂号；
- 4. 在线建档/无卡预约：初诊可使用手机APP在线建档功能，在APP上填写相关信息，完成在线建档；
- 5. 预约挂号放号时间：每日下午16:00投放第7天新号源，如本周一下午16:00投放下周一全天号源。
注意：预约挂号成功后48小时之内可在手机APP上退号，手机APP最迟退号时间是在就诊日期前一天中午12:00前。如预约挂号成功后超过48小时，且未到就诊日期的，请到医院收费窗口退号。若退号时间超过预约就诊日期的工作开始时间，一律不退号。
