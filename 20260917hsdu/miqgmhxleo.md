# 孕吐太难受，怎么办？

> 更新时间：2026-09-17 (UTC+8)

责任编辑：周寒鹰

每天呕吐都吐成了黄脸婆，什么美好孕期一点也不敢奢望了，这样呕吐下去，什么时候是个头啊？会不会影响宝宝的发育，要不要看医生？

 怀孕后，受激素的影响，吐啊吐的头晕、乏力、食欲不振...是不是让你难受极了？

其实怀孕初期的恶心呕吐视为正常反应，传统上称之为“害喜”了。多数在孕6周左右出现，8-10周达到高峰，孕12周左右自行消失，早孕反应的轻重因人而异。轻微的孕吐可以自护，如何减轻孕吐症状？

1.放松心情，清淡高蛋白饮食，少量多餐，保持口腔清洁，饭后漱口；

2. 保持大便通畅，避免因大便干结用力增加加腹压而加剧呕吐的气味、食物或添加剂；

3.及时补充叶酸，预防胎儿畸形；

4. 应尽量避免接触容易诱发呕吐减轻孕吐症状；

5.多听音乐、适当运动，和好友聊天，保持良好的心态。

医生，什么情况下需要住院治疗？

如果孕妈妈频繁呕吐每天超过6小时即为重度，无论吃什么就吐什么，就连喝水都吐，或体重较前减轻>5%，应该及时去医院，寻求医生的帮助，必要时住院治疗，切不可盲目硬撑。否则严重孕吐可能会引起脱水、酮症酸中毒等，也会影响孕妈妈和胎宝宝的身体健康。
