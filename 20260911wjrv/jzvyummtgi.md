# 在香港精子库申请无精做人工受孕大概要花多少钱？

> 更新时间：2026-09-11 (UTC+8)

之前向香港精子库**做人工受孕（试管婴儿、人工授精）费用在10000-120000元不等，因为我国法律规定，禁止精子卵子买卖，所以在香港精子库**是无偿的，无需支付费用，只要满足精子库申请条件即可。而做人工授精费用一般较为便宜，按照香港当地物价在1万元左右就能搞定，而试管婴儿受孕，就需要看做几代试管，一般向精子库**做一代二代试管费用在4-7万元不等，做三代试管在8-12万元不等。

根据香港经济日报HKET2018年报道，香港当地唯一的精子库（位于仁安医院仁安生殖医学中心），在经历5年多的时间，成功捐**子的男士不足30人。数量是较少的，而向香港精子库**做人工受孕费用具体如下：

- 1. 向香港精子库**做人工授精费用在10000元左右，包括检查、精液优化、人工授精手术等；

- 2. 在香港精子库**做一代试管费用在40000-50000元左右，包括检查、促排、促排、移植等；

- 3. 香港精子库**做二代试管费用在60000-70000元左右，比一代试管多出了单精子注射费用；

- 4. 向香港精子库申请无精做三代试管费用较贵，在80000-120000元，比一代二代多出了胚胎筛查费用。

香港的精子银行是香港家庭计划指导会开办的，但是很可惜，已经于2008年关闭，精子银行为香港市民提供了26年的服务。
